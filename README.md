# Macro Studio // Mouse

**PT-BR** · Gerador de macros gratuito para **qualquer mouse** no Windows 10 e 11. Programa criado por **NewRSX**.

**EN** · Free macro generator for **any mouse** on Windows 10 and 11. Created by **NewRSX**.

![Macro Studio // Mouse](macro-studio-mouse-v1.2.0-pt.png)

## O que faz / What it does

- Ação para cada botão (laterais, roda, meio): clique, segurar e clique duplo · Per-button actions: click, hold and double click
- Teclas e atalhos, texto, mídia/volume, abrir programas, trava de clique, modo sniper, gestos · Keys, text, media, launch apps, click lock, sniper mode, gestures
- Gravador e editor de macros (mouse + teclado) · Macro recorder and editor (mouse + keyboard)
- Autoclicker · Autoclicker
- Perfis por jogo/programa, com troca automática · Per-game/app profiles with automatic switching
- Testador de botões, velocidade de clique, clique duplo fantasma, polling rate · Button tester, click speed, phantom double click, polling rate
- Backup automático, exportar/importar tudo · Automatic backup, export/import everything
- Aviso de nova versão dentro do programa · In-app new version notice

O programa avisa sozinho quando há uma versão nova aqui no GitHub. · The program tells you when a new version is published here.
